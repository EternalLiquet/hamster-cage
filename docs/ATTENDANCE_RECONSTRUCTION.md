# Attendance reconstruction contract

`core-domain` accepts immutable source facts and an explicit `now`, returning sessions, credited intervals and review items. It has no Android, storage, UI or networking dependency. Calendar aggregation and departure estimates are separate features.

- Raw IDs with conflicting payloads, unknown offices, future events and unpersistable timestamps are retained in the caller's input and excluded with a review reason. Persisted timestamps must fit signed epoch milliseconds; duration arithmetic does not overflow by first converting to milliseconds.
- Equivalent observations are normalized by office, instant and transition, retaining all source IDs. At a simultaneous EXIT/ENTER boundary with an existing visit, the immediate reversal corroborates that visit under the [boundary stabilization rule](BOUNDARY_STABILIZATION.md). Without a preceding visit, ENTER/EXIT is a zero-length observation and cannot create grace credit. Ordering never depends on replay IDs. Repeated ENTER retains the first observed start without restarting grace; missing ENTER never invents a start.
- An automatic session stores its observed ENTER immediately. Its office's arrival walking grace is uncredited: the credited interval starts at `ENTER + arrival grace`, never before ENTER. An open session accrues only from that instant through `now`; an EXIT at or before the grace-window end gives that visit zero credit. The observed in-zone duration remains separately visible. Exit/departure grace affects a projected geofence departure only; it does not add accrued attendance to a closed or open session. Stale open sessions require review. Configured short-gap reconciliation requires both adjacent observed visits to have positive credit and may credit only their observed EXIT-to-next-ENTER gap within one office. A visit shorter than arrival grace blocks reconciliation on both sides; the engine cannot bridge across it. Reconciliation never fills the next visit's arrival walking window, so credited intervals may remain split. A final global union prevents overlapping offices or manual intervals from multiplying credit.
- Every credited interval contains its contributing session IDs and identifies gap reconciliation. Each session links to original raw IDs or one manual fact. Confidence is an explanation, not a credit multiplier.
- Manual observations are intervals, never synthetic device transitions. Corrections are separate immutable facts. The latest valid candidate uses its positive durable append sequence for precedence; legacy sequence-zero candidates use creation time then ID. Malformed candidates are reviewable and preserve original evidence. Conflicting correction IDs are excluded instead of resolved by input order. Reverting appends a marker that restores the original reconstructed bounds, confidence and review reasons while preserving every prior edit and its audit trail.
- Correction targets include the canonical session ID and aliases for every retained raw source ID. Late replay and repaired missing-boundary evidence therefore cannot silently orphan an earlier edit. Day detail uses `correctionTargetIds` to show the retained audit history. Room schema 2 adds the append sequence and revert marker through explicit migration 1→2; legacy records remain readable without destructive migration.

Issue #78 changes this arrival-credit policy; earlier split-day and grace-overlap totals are historical evidence for the superseded rule, not acceptance evidence for #78. Its focused verification must cover zero, shorter-than-grace, exactly-at-grace and longer-than-grace observation; EXIT before grace ends; zero arrival grace; open-session progression; and immutable source facts. Existing malformed-input, midnight/DST, overlap and correction safeguards still apply. Public tests use synthetic locations and dates. No runtime logs expose source facts.

For example, with five-minute arrival grace and a ten-minute short-gap threshold, observed visits 09:00–09:10, 09:11–09:12 and 09:13–09:20 earn 5m, 0m and 2m respectively: 7m total. The short middle visit blocks credit for both adjacent gaps and prevents a bridge across it.
