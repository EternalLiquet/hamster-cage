# Share one day's data

On Dashboard Today or a History date, open the day detail and tap **Share this day's data**. Review the short preview, choose an app, then send the JSON file only to a trusted recipient. To discuss a device problem privately, attach that JSON file in your private chat. No screenshots or coordinate lookup are needed.

The version-1 JSON covers the selected date in the attendance policy's timezone, from local midnight inclusive to the next local midnight exclusive. These are actual instants, so DST days can be 23 or 25 hours. It also includes raw observations linked to sessions touching that date and at most one earlier observation per related office from the preceding local day. If an EXIT occurs in the final two hours, it can include the first same-office return and first different-office presence within the first two hours of the next local day. The preview reports the count and evidence date span before a file is made. Longer-range evidence can still affect derivation, so this bounded file is diagnostic context rather than a guaranteed full engine replay.

The file includes immutable observation type, event time, receipt time, available location-fix time, source, and accuracy; aliases that connect related facts and sessions within this export; relevant manual intervals, corrections without notes, office radius/grace and policy, capture health, app version, and the resulting day summary. Alias numbers are stable within the same export but do not reveal stored IDs. Office names, exact coordinates, notes, credentials, and logs are omitted. Attendance times and patterns are still private. The file is diagnostic evidence, not a backup or an importable archive.

Nothing is sent automatically. Preview cancellation makes no file. Choosing an app creates an app-private temporary JSON file exposed only through a narrow read grant to the selected share target. Android share targets can keep their own copy. The app removes its temporary copy after one hour while running or on a later launch after that time; until then it remains in Android app-private cache. Deleting attendance history also deletes these app-owned temporary copies. If the share sheet is dismissed, the temporary file may remain in that cache until cleanup. Sharing does not change saved attendance, policy, or calculation results. No direct remote read or automatic future-day access is established.
