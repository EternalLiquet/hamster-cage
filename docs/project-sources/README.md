### What Hamster Cage should borrow

Use the image as aesthetic direction, not as a template to copy.

The app should translate these cues into an original dark-mode product design:

- deep charcoal/navy base instead of the bright yellow background;
- warm amber/gold primary accent inspired by the hair and background;
- muted orange/peach secondary accent inspired by the bow;
- restrained pink/magenta highlight inspired by the eyes/accessories;
- off-white text and pale cool surfaces inspired by the lab coat;
- subtle "lab badge / control panel" visual language;
- soft rounded geometry with a slightly playful hamster/lab flavor.

Do **not** make the UI look like a generic Material demo, but also do not turn every surface into character-themed decoration. The target is a modern personal utility with a small amount of recognizable personality.
